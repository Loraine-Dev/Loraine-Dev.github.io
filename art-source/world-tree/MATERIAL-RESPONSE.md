# 局部光学响应素材 · 当前版本

原始 world-desktop / world-mobile 主图与现有云雾未修改。

`npm run assets:living` 运行 `scripts/prepare-material-response.cjs`，从原画与 `src/data/living-regions.json` 重建区域遮罩和 128×128 光学场。详细源文件 SHA256 与职责见 material-response-manifest.json。旧 living-manifest / godray-manifest 记录上一版生成方式，仍保留作历史来源，当前 living 材质不再加载两个静态 godray 姿态。

- 遮罩 R：向内羽化的水面区域，排除石岸；G：有边界的叶簇亮度筛选；B：排除建筑的山谷空气响应区域。
- optical-field.webp：原创周期连续场。R 为云影透射，GB 为水面双向坡度。它是技术图，不是独立绘制的世界素材。
- living-shaders.ts：投影波面法线重采样原倒影；云影场同时控制叶簇受光及沿原画光源方向的局部散射。
- living-scene.json：水位移、地平线、光源、增益、周期和设备帧率上限。

**没有的素材**：独立叶簇、独立水面/倒影、干净背景修复图、深度/法线渲染层、独立瀑布。不能据此实现可信的树冠轮廓摆动、水面几何遮挡变化或瀑布流动。若需要这些效果，应由美术补充：配准的树冠前/后叶簇 RGBA + 去树背景；无石岸的干净水面/倒影层 + 水体深度/法线；瀑布独立 RGBA/流向图 + 背景修复。当前不伪造这些成果。

合成审查：shore 独立前景包含大量湿石反光，覆盖远景水面材质的一部分。最醒目的前景金色反光不能当成开阔湖水做波形扭曲；当前只处理能确认的远景开阔水域。明显前景水波仍受素材限制，需要与石岸正确分离并配准的水体/倒影/遮挡层。不得靠提高 gain 掩盖该限制。

本轮正常画面录制来自生产预览 4177，不含开发调试界面。独立视频来自开发预览，依次关闭 4 秒 / 单项开启 14 秒 / 关闭 4 秒，截图和编码开销会使完整录制时长稍长。均为正常速度，软件图形录制不代表实体手机表现。
