## 艺术自审与取舍

主视觉保持暗门框住亮树的焦点关系、桌面左侧品牌区和手机下方品牌区。没有重绘或降低主画清晰度。两层已认可云雾保留；统一的云谷光路替代原先树光和水光独立循环。光源位于树后，光路经地形遮挡，仅影响空气层。维持轻量镜头的前后景相对位移。

光路使用两张预制透明姿态做 28 秒往返过渡，不是物理体积光模拟。云雾是真正位置变化与形变。没有新增水波、瀑布流动、整树摇动或粒子，因为当前独立素材和可得收益不足。场景运动仍需用户通过正常速度 A/B 判断是否值得。

内页通过墨色/纸色、宋体/无衬线层级、宽窄行长和留白形成节奏。作品页以两条节奏相遇的原创 SVG 谱面表达研究方向，明确标为非游戏画面。审查中删除了裁切后不完整的谱面装饰英文，并收起最低波峰以避免文字区与线条重叠。关于页解释品牌世界与游戏画面的区别；日志页显示无真实文章的空状态；联系页仅链接 GitHub。

首页长截图会把 sticky 镜头占用的滚动距离呈现为静态空白，因此正式验收图集使用实际滚动位置的分屏截图。艺术验收工具本身不进入生产构建。

## 技术验证

已实际运行：

- `npm run build`：内容生成、TypeScript 和 Vite 多页构建通过。
- `npm run test:unit`：9 项既有空间映射、镜头边界与策略检查通过。
- `npm run test:site`：4 项内容/Markdown 检查；六页 × 1440×900、768×1024、390×844、320×740，共 24 组路由和视口检查通过；站内链接无失败、无水平溢出、无捕获到的页面异常或资源错误。
- `node tests/world-browser.mjs`：1920、1440、1280、768、390、375、320 宽度场景检查，以及按需 WebGL、上下文丢失/恢复、快滚、触控模拟、跳过链接、无 JS、无 WebGL、低内存和省流回退通过。Edge 155.0.4283.62 与 Firefox 153.0 的场景和布局检查通过。
- `npm run test:godrays`：A/B 不重置云雾、暂停保持相位、后台暂停/恢复、减少动态恢复、手机素材切换、低内存不请求光路、无 WebGL 和光路资源失败回退通过；生产没有开发面板。
- `node tests/cloud-flow.mjs`：正常速度 5 秒内云雾产生真实位置变化，密度不靠透明度变化冒充运动。
- `node tests/motion-compare.mjs`、`node tests/motion-debug.mjs`、`npm run test:environment`：开发对照与诊断、独立开关、后台/暂停/减少动态、静置 WebGL 不持续重绘通过。

替换环境结构后，旧环境容器从四个模块变成两层云雾，光路位于独立容器；相应测试计数由 4 改为 2。未修改原像素变化测试阈值，也未以测试计数代替实际视觉判断。
