# 候选 A：穿过云谷的光 · 实现与验收

2026-10-20。本轮完成首页创意审查、一个最小候选与真实开关对照。尚未通过用户美术验收，不建设内页，不部署。基线 fda8eac，回滚分支 `codex/before-godray-study-20261020`。

## 创意审查

焦点是世界树与树后暖光；桌面左品牌/右树，手机上树/下品牌。最强魅力是暗门框包围亮世界，以及门、岸、遗迹、云谷的纵深和宁静向往感。现有画面不缺对象。弱项是源光与空气之间的关联：在银白叶片、原有亮倒影上继续加光，边际收益有限。

只实现 A。云雾与交互已有较高杠杆，保留；整树、天空大背景、瀑布和水体不新增独立运动。树的生命感由树后光路、流动空气与既有高光共同承载，不让树表演动画。

## 与上一轮局部高光实验的区别

上一轮 `?artStudy=light` 修改的是叶冠和倒影的亮度关系，未得到“气质巨大提升”的证据。本轮没有将该实验升级为默认版本，而是直接在树后通向左侧云谷的空气中建立光路。

主画、门体、近岸、云带素材与云雾参数没有修改。候选中暂停并隐藏旧树光/水光六条时间轴，保留原画本来就有的树与倒影。新增两张不同光分布的局部 alpha 场，28 秒同周期缓慢交替，光源位置固定，软光的角度和局部密度有所差异。不是整张图曝光起伏，也没有移动世界树。

这是**预烘焙散射光的 2.5D 表现**，不是运行时物理体积散射、粒子或流体模拟。光路在构建时结合方向衰减、软角宽、预烘焙密度、手工地形轮廓与原画明暗保护；所有遮挡都固定在绘景坐标。它适用于当前受控镜头，不支持任意绕行。

## 素材、配置与维护

唯一调参入口 `src/data/godrays.json`：

- `period` 毫秒、`initialPhase` 起始相位、`blendRange` 两张光分布交替范围。
- 桌面/手机 `source` 为主画内归一化光源坐标；`beams` 每项是 `[方向角度,软角宽,相对能量]`。
- `poses` 是两种细小角度分布，`reach` 控制衰减距离；`airBand` 给出上下软边。
- `occluder` 是地形遮挡轮廓；`alpha` 是烘焙上限，`strength` 是运行显示强度。手机使用独立布局和强度，没有裁切套用桌面光路。

`npm run assets:godrays` 使用确定性技术生成器 `scripts/prepare-godrays.cjs`，只读取已有原始主画，不重画主视觉。生成四张 alpha WebP、`src/data/godray-assets.json` 的统一裁切边界，以及 `art-source/world-tree/godray-manifest.json` 的来源/哈希清单。密度是一次性烘焙的技术纹理，没有全屏噪声滤镜。没有第三方素材。

实际资源：桌面两张共 50354 字节，手机两张共 22084 字节，按当前方向加载。裁切矩形占各自世界绘景约 15.2% / 8.7%，不是全屏后处理，也不等同于实测 GPU 耗时降幅。换主图时必须重新对齐源光和遮挡，再重新生成与预览。

`src/dev/godray-study.ts` 管理本地原型、开关、素材解码和生命周期。两张光分布用原生 Web Animations API 处理透明度；没有新增 RAF、Canvas 或 Three 场景。活跃环境时间轴由基线 14 条变为候选 10 条（8 条既有云带 + 2 条光路过渡）；旧光时间轴保留但暂停，方便回滚。

光层与绘景处在相同坐标/投影中，门体和近岸仍在其前方。原相机、深度与滚动逻辑没有修改；本轮没有顺便实施候选 B。

- 手机：http://127.0.0.1:4176/review/godrays.html?device=mobile

- 初始关闭：http://127.0.0.1:4176/?artStudy=godrays&study=off

左下角只切换本次体积光，**两侧云雾始终保留**。候选两种状态都收掉旧树光/水光，以隔离本次改动。底部原有暂停按钮仍暂停所有环境动态。默认首页不启用候选；生产构建不显示该 UI 或请求这些光层。

`artifacts/godray-study/final/` 保存桌面 1440×900、手机 390×844 的开/关原始 WebM、0/5/15/24/进入/30 秒截图与完整 JSON。视频正常 1×，前 24 秒没有输入，随后两侧使用相同原生滚轮输入。开始仅对齐两侧云带相位，之后正常运行。MP4 按加载余量裁出观察窗口，没有加速、插帧或用静态截图造动画。桌面并排 30 秒，手机约 29.96 秒；左关右开。

录屏中两端的四个状态均无捕获到的 JS 异常或资源失败，初始 scrollY=0。相同滚动下桌面两侧 cameraZ 均为 2.9630，手机均为 3.1124，说明没有拿不同镜头制造 A/B 差异。截图名是名义采样点，准确采样时刻见 JSON。

第一轮桌面已能看见空气中的柔光；手机版第一轮偏弱，之后只调整其独立光层强度。实际检查中主画未整体明暗起伏，门体在前、主要岩壁保留遮挡，树冠轮廓稳定。是否带来足够的美术提升仍须用户观看实录与实时预览判断，不能用时间轴或像素门槛代替验收。

## 性能、回退与验证

已通过构建/类型检查、9 项原有单测、environment/flow/idle 浏览器回归、上一轮独立原型回归和新 `test:godrays`。新检查覆盖两种视口、云带节点和相位不重建、14→10 活动时间轴、真实暂停后时间保持、后台事件模拟、减少动态初始跳过及恢复、响应式切换、低内存不请求素材、无 WebGL 仍可显示，以及素材失败回退到主画与云雾。视频完成解码检查。

暂停检查等待原生 WAAPI pending 状态完成再取样，随后要求时间完全不变；没有放宽原有测试阈值。新增原型仍有两张纹理与局部 screen 合成成本，不能据时间轴数量宣称没有 GPU 成本。没有物理手机帧率、功耗或新 Lighthouse 结果，不宣称 60fps。
