## 阶段 B / 完整站点

Home 是电影式主景、自然滚动和品牌/作品叙事；Works 是单款计划作品的数据展示；Philosophy 使用纸色画册排版；About 说明独立游戏品牌与策划研究阶段；Journal 支持真实 Markdown 与诚实空状态；Contact 仅 GitHub。作品图形明确标注非游戏画面。无假实机、假角色、团队规模、法律身份、日期或游戏成果。

组件已位于 scripts/site；结构化品牌、文案和作品资料位于 src/data；Journal 位于 content/journal。全站基础设计变量统一到 src/styles/tokens.css，原数值不变。没有通过统一背景或堆卡片来补齐页面。

## 阶段 C / 环境动态

沿用 de168d2 的三项局部纹理处理与原云雾：地形遮挡光路、限定水域的倒影折射、树冠受光纹理。局部处理与镜头空间同步。没有天空独立明暗循环，没有瀑布移动或树轮廓摇动。

新增遮罩改为无损 WebP；桌面 87682→28952 B，手机 81824→28590 B。逐像素解码比较与原 PNG 一致。原 PNG 保留作参考，绘画和云雾参数未改。局部材质为 2D WebGL 近似，非真实体积渲染，也非独立枝叶动画。

开发六模式对比仍在，生产无诊断 UI。增加可检查的运行状态，统一当前整站暂停、后台、离屏和减少动态回归。旧光路研究测试保留为历史命令，不用其结果证明新材质。

软件 WebGL 单独限制为每秒最多6次材质绘制，保持完整采样尺寸、真实时间相位和云雾速度；不把软件录屏的流畅度当成硬件GPU或实体手机结果。仅云雾模式不再运行空材质循环，并缓存着色器 uniform 位置，减少无视觉收益的工作。

## 阶段 D–F / 验收与发布

本次技术检查、当前构建的截图、录像与性能结果随交付目录附报告；不得把旧版本性能数据充作当前数据。性能采集与其他浏览器压力检查分开执行。

用户重点验收：水域边界是否自然；树冠与天空是否被误染；光束是否贴片；手机裁切、文字和动态是否互相抢夺；正常速度 5–10 秒能否察觉云之外的变化；30 秒是否有重影、闪烁、明显机械重复。技术通过不能回答这些艺术问题。
