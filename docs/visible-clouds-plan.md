# 可察觉的局部生命感 · 执行计划

本轮按用户明确的三个部分直接实施，不重做主画、不更改既有测试阈值、不部署。上一轮像素变化不足以通过实际观看验收。

选择局部透明云带素材而非提高全图曝光或实时体积渲染：前者能以少量合成层提供可辨认轮廓，后两者分别不解决位置变化与超出最小修改范围。

1. 先记录回归：云雾透明度恒定时，5 秒内仍必须发生空间形变/位置变化；开发预览必须可一键切换原画静态与动态。旧实现应失败。保留旧测试门槛。
2. 新增一张独立透明云素材，保存源 PNG、提示词、生成来源与优化脚本。现有前后景主画不变。两层既有遮罩内，各两片云以不同方向/尺度运动，固定大体密度，局部缓慢形变；保护岩壁/建筑轮廓。
3. 云雾先在真实浏览器 0/2.5/5 秒固定视口录屏审查，观察轮廓位移而非仅靠差值。若未可辨认，继续调整此阶段。
4. 再用现有树冠遮罩制作两束符合右侧光源的窄、软局部斜光，缓慢有向扫动，避免全冠闪烁。保留既有受控镜头，仅按实际浏览器验证轻量前后相对位移。
5. DEV 一键静态/动态按钮隐藏全部环境层且冻结镜头响应；减少动态/后台暂停保持。生产包无诊断 UI。
6. 桌面与手机同视口静态/动态各录制 30 秒、正常 1 倍速度。录制前 15 秒不输入，后半程验证滚动。跑原有测试及新行为测试，记录边界与素材限制。保留分支与回滚版本，打开预览，用户做最终审美验收。
