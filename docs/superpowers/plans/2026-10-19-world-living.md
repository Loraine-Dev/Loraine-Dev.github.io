# 首页生命化实施计划

目标：保持 797a3f9 主视觉像素与品牌版式，仅添加局部环境生命感。用户已授权直接实施最小动态方案，完成后等待验收，不发布。

架构：保留 Three.js 透视门体/近岸；远景原图以等价投影 DOM 图层显示，局部软遮罩内 CSS/WAAPI 合成运动。Three.js 改为仅在镜头或视口变化时绘制，环境动效不驱动全屏 WebGL 连续渲染。不引入新运行依赖。

- [x] 审计：确认独立素材与烘焙内容；保存回滚分支。现有世界树/建筑/云/水属于同一绘景，门和近岸有 alpha。
- [x] 云雾：由确定性程序生成透明雾纹理；手工定义桌面/竖幅软遮罩，亮度保护避开岩体；先在浏览器验证。
- [x] 树光：独立叶冠亮度遮罩；不移动树形，不改全图曝光；浏览器检查。
- [x] 相机：DOM 远景与 Three 相同透视投影同步；手机缩短推进；输入正常滚动，不加滚动拦截；快速滚动回归。
- [x] 水：仅在反射平静区域使用低振幅局部光照，瀑布保持静态；若检查失败关闭。
- [x] 验证：配置开关、后台/离屏/暂停/减少动态停止、30 秒真实运行帧序列、循环边界、30+ 秒录屏和滚动。保留源图哈希、参数与素材来源文档。

参数集中 src/data/environment.json；对应运行 src/scenes/environment.ts，遮罩源 art-source/world-tree/motion-regions.json 与生成脚本。测试：先证明投影/局部开关缺失失败，再实现；浏览器检查遮罩边界与暂停；不把测试通过当作美术合格。
