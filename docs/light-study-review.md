# MILOQEN · 设计杠杆评审与单一原型

2026-10-20。用户已认可当前主视觉与云雾；本轮不重做首页，不部署，仅用一个独立原型比较新增设计是否值得。基线 `478f34b`，回滚分支 `codex/before-light-study-20261020`。

## 画面判断

桌面左侧暗部和留白承载品牌，右侧大树是主焦点；金色石桥与湖面反射把视线从门槛引向树干。冷青蓝天空和暖金光源的关系已经成立。门体、近岸、遗迹、云谷形成清楚的远近秩序；宁静、神秘和向往感来自这种收束与显露。

手机采用上树下字的纵向构图，湖面是世界与品牌之间的视觉连接。这里尤其应该保留反射的材质，避免增加发亮的色块或把树冠进一步烧白。

现有图像并不缺元素或细节。最有价值的机会在于强化现有关系，而非增加可运动对象。当前树光游走与水面独立明暗来自同一画中光源，却各自循环；统一其节奏具有低成本试验价值。原镜头已有空间感，门体也已足够暗，另两种候选的边际收益与风险须一起考虑。

## 三个候选，仅实施 A

| 方案                     | 预计视觉收益                                       | 实现复杂度                         | 性能成本                                         | 对美术品质的影响                           | 后期维护                         |
| ------------------------ | -------------------------------------------------- | ---------------------------------- | ------------------------------------------------ | ------------------------------------------ | -------------------------------- |
| A 云隙透光：同源光的路径 | 中高；同时连接树冠、反射、冷暖与焦点，减少独立游走 | 低；复用现有层和时间轴             | 低；已有 opacity/transform，局部反射 screen 合成 | 风险是高光过亮或反射成光斑；限制范围和上限 | 低；一个 JSON 控制曲线与两端强度 |
| B 越过门槛：镜头构图接力 | 中高；强化抵达感，控制推进后树冠完整性             | 中；需两种构图、门体遮挡与位移重校 | 低至中，主要在交互绘制时                         | 可能破坏已认可构图，不能仅凭相机数学验收   | 中；换图与改断点都要重新校验     |
| C 门内外明暗分区         | 中；增加远近与视线引导                             | 低                                 | 很低                                             | 门体本已暗，易丢失雕刻；新增暗化的收益有限 | 低；少量色调参数                 |

选择 A 的理由是它能同时处理光影连贯性、视觉引导和多余循环，而不需要新素材、几何体或相机改造。B、C 未实现。

## 最小原型的实际范围

- 云雾源图、遮罩、位移、形变、密度、节点与动画对象均保持；A/B 不重建它们，也不重置相位。
- 树冠原有三条变换时间轴改为固定光路，原有透明度时间轴负责一次透光；没有增加第三束光。
- 原有水面变换固定，原有透明度时间轴使用同一能量曲线。只对现有反射区域给出弱的同源受光反馈，没有水流、波纹位移或瀑布运动。
- 两个受光区域共用 32 秒曲线，相位一致、强度不同；手机有独立强度。它是美术编排的共同曲线，不是云遮挡的物理光照模拟。
- 14 条原有动画仍是 14 条，没有新美术 DOM 层，没有额外 RAF 或 Three 场景。局部反射新增 screen 合成处理的是原有裁切区域，不能据此宣称 GPU 成本为零。
- 关闭原型恢复保存的原始 keyframes、timing 与相位；云雾与镜头继续原速运行。暂停、后台、离屏、减少动态、低内存与省流策略保留。
- 仅 DEV 查询 `?artStudy=light` 加载控制与样式。默认首页和生产预览不启用该原型，不显示新 UI。

## 实际审美结论与边界

同视口检查中，树冠与反射的起落关系更一致，独立光束游走减少。增益集中在连贯性，画面变化克制。原画既有暖光和金色反射已经很强；继续提高反射幅度会损伤波面材质。**没有足够依据宣称本原型让整张图产生巨大美术提升，因此没有并入默认首页。**

保留这个低成本、可撤销的实验供用户判断投资回报；若用户认为实际对比收益不足，应直接舍弃这项受光改动，不继续制作水面/瀑布动画来补偿。当前主视觉和云雾是受到保护的基线。
