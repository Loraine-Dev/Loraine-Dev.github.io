# MILOQEN V1.0 RC · 完整官网验收报告

日期：2026-10-21（Asia/Shanghai）。本地待用户艺术验收，未推送、未部署、未覆盖正式网站。

## 实际功能

Home、Works、Philosophy、About、Journal、Contact 均有独立静态路由、共享导航、SEO、手机菜单、页脚和合理构图。首页主视觉、云雾和原画文件保持不变。首页下滑可进入品牌、计划作品和余韵，镜头保持前后层相对运动；内页不加载首页材质。设计变量集中于 tokens.css；作品与文案数据化；Markdown 管线支持真实文章、草稿和撤稿。目前无真实文章，显示空状态。

《奇妙拍档》为策划与研究中、尚未正式开发的原创节奏游戏，计划手机与PC。图形概念标为非游戏画面，没有假角色、实机、试玩、发布日期、规模或法律身份。GitHub 是唯一确认的官方外链；TapTap 按用户明确指示保持 url:null、confirmed:false，未来确认后在数据中开启。没有联系表单。

## 首页动态与素材边界

- 云雾：沿用认可的远中两层独立云纹理和遮罩，位置、速度、形变不变。
- 光路：树后原光源通往云谷，使用原独立地形遮挡姿态，增加连续束形和局部影纹变化。
- 水面：新增限定区域遮罩，原倒影局部重采样，使用不同方向与波长的微波纹，不移动整张水面。
- 世界树：亮度限定的局部受光纹理变化；主干与树冠轮廓不动，没有独立枝叶摆动。
- 天空、瀑布与门前湿石：不强制新增循环。缺少独立瀑布、枝叶、背景补全/深度素材；宁可保留静态，不用假裁片流动代替。

这是2.5D纹理处理，非真实体积光模拟。当前对照可独立关闭/显示全部、光、水、树、云。生产保留暂停与减少动态，排除开发面板。后台/离屏停止额外绘制；低内存、省流、无WebGL有原画回退。独立材质上下文丢失时保留静态层，需重载重建，不强制打断滚动。

桌面材质更新上限18次/秒、手机15次/秒，检测为软件WebGL时降至6次/秒，保持采样精度与真实时间相位。这是配置上限，不是实测帧率。实体手机和硬件GPU的实际表现仍需人工检查。

## 仍待确认的问题

1. 用户尚未通过首页动态艺术验收：需判断5–10秒内云之外的运动是否明显自然，水域羽化、树冠天空边界是否贴片，30秒是否有机械重复、闪烁或重影。初步抽帧未见硬切边不等于连续观看合格。
2. 性能目标未达，冷启动主线程阻塞仍存在；应在实体手机和独立环境复核，不能以构建成功判定可正式发布。
3. 独立瀑布、枝叶、真实体积光与天空独立动画未实现，属于明确的素材/投入取舍。
4. TapTap公开链接暂未提供，按指示不阻塞本版且不展示。
5. GitHub写入权限本轮未重新测试，远端Pages工作流未执行，不声称遇到新的403或已上线。
