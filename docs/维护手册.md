# 弥洛生完整官网维护手册

## 当前交付状态

这是待艺术验收的完整静态网站，不代表已正式上线。六页、404、作品数据和创作记录管线已实现。首页保留原主视觉，采用两层云雾、两张云谷光路姿态和已有按需空间镜头。内页没有 WebGL 或首页动态资源。当前作品真实状态为策划与研究中，尚未正式开发。

## 启动与构建

要求 Node.js 24（与锁定依赖匹配）。首次运行 `npm ci`。

- `npm run dev`：先生成内容，再启动 `http://127.0.0.1:4176/`。
- `npm run build`：生成页面、TypeScript 检查并构建 `dist/`。
- `npm run preview -- --port 4177`：查看生产构建，首页无开发诊断面板。
- `npm run test:unit`：已有空间映射与性能策略单元检查。
- `npm run test:site`：先启动 4177 预览，检查内容生成、安全 Markdown 和全站真实浏览器。
- `node scripts/audit-site.mjs`：本机 Chromium + Lighthouse 移动模拟，报告在 `artifacts/complete-site/`。运行时应停止其他自动浏览器压力测试。

`index.html`、五个内页目录的 `index.html`、`404.html`、sitemap 与 robots 是生成结果。不要手动修改生成页面。修改内容后重新 `npm run build`；开发中只改 JSON/Markdown 时，可运行 `node scripts/render.mjs` 刷新页面。

## 内容入口

| 文件 | 负责内容 |
|---|---|
| `src/data/site.json` | 品牌、宣言、官方 GitHub 与首页基础信息 |
| `src/data/works.json` | 作品数组，增加作品仅增加数据项，静态模板自动循环 |
| `src/data/editorial.json` | 理念、关于、首页介绍、日志空状态与联系文案 |
| `content/journal/*.md` | 真实创作记录，README 不参与发布 |
| `scripts/site/components.mjs` | 共享导航、页脚、SEO、原创概念谱面 |
| `scripts/site/pages.mjs` | 内页与首页正文布局 |
| `src/page.html` | 首页原有场景模板，构建时注入导航和后续内容 |
| `src/styles/site.css` | 原有主视觉构图与环境样式 |
| `src/styles/editorial.css` | 全站排版、空间、纸色/墨色、菜单及响应式 |

不要把策划中的作品写为已有开发成果；不增加假截图、假日期、假邮箱或无法工作的表单。概念谱面是代码原创 SVG，明确标为非游戏画面。

## 发布真实文章

参见 `content/journal/README.md`。JSON front matter 需要 `title`、`summary`、有效真实日期 `date` 与 `published:true`。文件名决定 URL，例如 `first-note.md` 对应 `/journal/first-note/`。草稿 `published:false` 不输出。构建自动更新目录、SEO、文章页和站点地图。

支持常用的有限 Markdown：标题、段落、列表、引用、加粗、行内代码和 HTTPS 链接。HTML 会转义，不执行嵌入内容；不支持表格、原始 HTML、复杂嵌套或任意 iframe。文章应以二级标题开始，页面主标题来自元数据。

`.generated-journal.json` 是生成路由清单。文章撤回或删除后，构建只删除该清单内旧文章的生成 `index.html`，不递归删除目录或其他文件。保留该清单进入 Git，避免草稿撤回后遗留旧公开页面。

## 环境动画与画面来源

- 原画与拆层：`art-source/world-tree/`、`public/art/world-tree/`。沿用现有品牌主图，不重绘。
- 云雾参数：`src/data/environment.json`；位置：`environment-regions.json`；实现：`src/scenes/environment.ts`。
- 云谷光路参数：`src/data/godrays.json`；裁切信息：`godray-assets.json`；实现：`src/scenes/godrays.ts`。
- 光路生成：`npm run assets:godrays`。输入为现有绘画，输出透明 WebP，来源与哈希在 `art-source/world-tree/godray-manifest.json`。
- 空间镜头：`src/data/world.json`、`src/scenes/world-scene.ts`。按交互绘制，非持续实时 3D 渲染。

光路是技术制作的 2.5D 透明姿态过渡，并非真实体积光模拟。28 秒往返，光源固定；使用原画亮度及地形遮挡，仅影响云谷空气区域。没有新加整树、瀑布或水波动画。旧树光/水光被新光路取代，不再创建或请求。云雾系统仍使用被认可的独立云素材及遮罩。

减少动态、低内存/省流会保留高质量静态画面；后台或离开场景会暂停动态。暂停按钮同时控制环境和镜头。`/?artStudy=godrays` 仅在开发环境显示光路 A/B 控件；`/?debugMotion=1` 显示现有诊断工具，生产不显示。不要用加速模式录像替代正常速度验收。

更换主画时必须重新校准云遮罩、光源坐标、地形遮挡和手机构图，不能直接沿用旧蒙版。当前没有独立瀑布流动与水体位移图；未来只有收益足够且素材可靠时才制作。

## 发布前后

本轮只在本地提交，不推送，不触发正式发布。`.github/workflows/pages.yml` 没有 push 触发器。验收通过后，由有权限的人将代码合入仓库，Settings → Pages 选择 GitHub Actions。检查已有工作流，避免其他遗留部署流程在 push 时发布。手动运行 `Publish reviewed website` 并输入 `MILOQEN-PUBLISH` 才会构建和部署。

工作流尚未在远端执行验证。它使用官方 checkout、setup-node、upload-pages-artifact 与 deploy-pages；构建使用 npm 锁文件。站点针对用户主页根路径部署，正式域名固定为 `https://loraine-dev.github.io/`。若改为项目子路径，要同时调整 canonical、sitemap、404 的根链接和静态资源路径。

发布后验证六页直达、404、手机导航、静态回退、GitHub 链接和资源响应。不要把本地预览可访问写成正式上线成功。
