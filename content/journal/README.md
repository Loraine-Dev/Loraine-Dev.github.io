# 创作记录目录

此文件不会作为文章发布。当前没有公开文章，不创建示例文章。

新增 `slug.md`，文件头使用 JSON 元数据（避免 YAML 解析歧义）：

    ---
    {"title":"真实标题","date":"2026-10-20","summary":"真实摘要","published":true}
    ---
    ## 正文标题
    真实正文。

文件名仅用小写字母、数字与连字符。日期应为真实发布日期。支持段落、1–3 级标题、无序列表、引用、加粗、行内代码和 https 链接。原始 HTML 会转义；不支持嵌入脚本。published 不为 true 的草稿不输出。
