# MILOQEN / 弥洛生

静态游戏官网，包含响应式布局、星尘粒子、柔和轨道动效、品牌介绍及《奇妙拍档》项目预告。

## GitHub Pages 发布
1. 在 GitHub 账号 `Loraine-Dev` 创建 **Public** 仓库，名称必须是 `Loraine-Dev.github.io`。
2. 将本文件夹中的 `index.html` 和 `assets/` 目录上传到仓库根目录并提交。
3. 打开仓库 `Settings → Pages`，将 `Build and deployment` 的来源设为 `Deploy from a branch`，分支选 `main`，目录选 `/(root)` 并保存。
4. 等待 GitHub Pages 发布，然后访问 `https://loraine-dev.github.io/` 检查页面。只有确认访问成功后，才把网址填进厂商资料。

注意：MILOQEN 名称及图形尚未获得商标可用性结论；网页中没有虚构游戏发行日期、团队成员或联系方式。
